# ブラックジャック・デュエル

2人対戦のブラックジャック（RULES v5.1）。カジノの「客 vs 店」ではなく、**人 vs 人**で駆け引きするのが特徴です。ブラウザだけで動く1ファイル構成のWebアプリで、合言葉を使ったオンライン対戦とCPU戦に対応しています。

---

## ルール

### どういうゲーム？

手札の合計を **21 に近づける**ゲームです。ただし **22 以上になったら、その時点で負け**（バースト）。2人で対戦し、より 21 に近い方が勝ち。勝った方が場のチップ（ポット）を総取りします。

### カードの数え方

| カード | 数え方 |
| --- | --- |
| 2 〜 10 | 書いてある数のまま |
| J・Q・K | すべて **10** |
| A（エース） | **1 でも 11 でも、都合のいい方** |

エースは柔軟に扱われ、画面の合計欄は常に**自動で一番いい数え方**になります。

### 用語

| 言葉 | 意味 |
| --- | --- |
| ヒット | カードを1枚引く |
| スタンド | もう引かずに確定する |
| バースト | 22以上になること。負け |
| ナチュラル | 最初の2枚がちょうど21（A＋10札）。最強の手 |
| ディーラー | 後攻の席。**毎ハンド交代**する |
| ノンディーラー | 先攻の席 |
| ポット | 場に積まれたチップ。勝った方が総取り |
| アンティ | 参加費。毎ハンド自動で払われる（後攻 9 / 先攻 10） |

### 1ハンドの流れ

1. **配札** … 2枚ずつ配られる。**1枚は表向き（相手にも見える）**、**1枚は裏向き（自分だけ見える）**
2. **ベットラウンド** … 賭けるかどうかを決める（1回だけ）
3. **サレンダー判断** … 勝てそうになければ、半額だけ払って降りられる
4. **ドロー** … カードを引くか止めるかを決める。先攻 → 後攻の順
5. **ショーダウン** … 裏向きのカードを公開して勝敗を決める

### 普通のブラックジャックとの違い

- **両方がカードを引く** … 相手は人間なので、どこで止まるか分からない。そこを読むのが中心。
- **引いたカードは相手にも見える** … 隠れているのは最初の裏向き1枚だけ。
- **バーストしても相手には分からない** … 外からは「止まった」ようにしか見えない。両方バーストなら**後攻（ディーラー）の勝ち**。
- **引き分けは先攻（ノンディーラー）の勝ち** … 後攻は「同じ」では足りず、必ず上回る必要がある。

### 勝敗の決まりかた（上から順に判定）

1. 22以上（バースト）した方が負け
2. **ナチュラル**（2枚で21）は、3枚以上で作った21に勝つ
3. より21に近い方が勝ち
4. 引き分け → **ノンディーラー（先攻）の勝ち**
5. 両方バースト → **ディーラー（後攻）の勝ち**

「これ以上引いたら100%バーストする」状態になると自動的にスタンドします。

### 特別な手

- **ダブルダウン** … 賭け金を倍にする代わりに、1枚だけ引いて強制スタンド。最初の2枚のときだけ宣言可。相手は「同額払って残る」か「降りる」の二択。宣言者は引き分け／両方バーストの裁定を自分有利に上書きできる。
- **スプリット** … 最初の2枚が同じ数字のとき、手札を2つに分けて2回勝負。賭け金とポットも半分ずつ。裏向き札は公開される。各手札にヒットは可、ダブルダウンは不可。
- **インシュランス（保険）** … 相手の表札が A か 10札のとき、賭けとは別枠で買える。相手がナチュラルなら勝負は無効となり全額戻る。外れれば保険料はポットに没収。素の確率はわずかに損になるよう設定されており、**カードを数えた成果を現金に換えるための手**。
- **サレンダー** … まだ1枚も引いていないとき限定で、賭けた額の半分だけ払って降りる。

### 賭けの部分

| 行動 | 意味 |
| --- | --- |
| チェック | 賭けずに次へ進む |
| コール | 相手が上乗せした分に合わせる |
| レイズ | 賭け金を上乗せする |
| フォールド | 降りる（払った分は戻らない） |

**オールイン**は手持ち全部を賭けること。相手が払いきれない分は返却される。

### カウンティング

山札は **2デッキ（104枚）を使い切るまでシャッフルせず**に使います。どのカードが出たかを覚えておくと有利で、画面上部の「残り」ボタンから残枚数とハイロー・カウントを確認できます。これは正規の技術で、隠す設計にはしていません。

### ゲームの終わり

チップは各200から。**どちらかが0になったら終了**です。

## リポジトリの内容

### 構成

```
blackjack-duel/
├── index.html   … アプリ本体（HTML / CSS / JS を1ファイルに同梱）
└── README.md    … このファイル
```

ビルド不要。`index.html` をブラウザで開けば動作します。

### 対戦モード

- **CPU と対戦** … オフラインで完結。相手は手役の強さと簡単なカウントで判断するAI。
- **合言葉で対戦** … 2人が同じ合言葉を入力するとマッチング。合言葉に中継URLを添えた `合言葉#xxxx` 形式で共有すれば、相手はURL入力不要。

### 通信のしくみ

- Cloudflare Workers 上の**中継サーバー（WebSocket）**をリレーとして使用。既定のリレーURL（`wss://bjduel-relay.bjduel-relay.workers.dev`）が埋め込まれています。
- 送り合うのは**プレイヤーの行動履歴だけ**です。両端末は種付き擬似乱数（xorshift32）で同じ山札を再現し、同じ行動を同じ順序で適用することで、常に状態が一致する**ロックステップ（決定論的リプレイ）**方式を採っています。
- ハートビートで接続を監視し、アプリの切り替えや一時切断からの復帰にも対応。進行中の対局は `localStorage` に保存され、タイトル画面の「つづきから」で再開できます。

### 実装メモ

- 描画は状態からペイロードを組み立てて反映する方式で、**自分視点／相手視点**を同じロジックから出し分けています（伏せ札の見え方など）。
- ルール全文はアプリ内の「ルールを読む」シートにも収録されています。
- スマホ表示前提のレイアウト（セーフエリア対応、カード枚数やスプリットに応じた自動縮小）。

### 遊びかた

1. `index.html` をブラウザで開く。
2. **CPU と対戦**ならそのまま開始。
3. **合言葉で対戦**なら、片方が合言葉を決めて相手に伝え、両者が同じ合言葉を入力する。
